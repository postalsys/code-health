How the numbers are made

Source lines
Lines carrying code, after dropping blank lines and comments.
Cyclomatic complexity (CC)
Independent paths through a function: 1 plus every if, loop, case, catch, ternary, && / || / ??, optional chain and default parameter. Above 10 a function is commonly considered hard to test, above 20 hard to understand.
Maintainability index (MI)
Per function, max(0, (171 - 5.2 ln(Halstead volume) - 0.23 CC - 16.2 ln(lines)) * 100 / 171), the 0 to 100 scale Visual Studio uses: below 20 is poor. The repository figure weights each function by its lines, so a large function counts for more than a small one. Code outside any function (lookup tables, schemas, declarations) counts toward size only. MI is driven mostly by size, so read it as a trend, not a grade.
When the language changed
A move from JavaScript to TypeScript adds type annotations to every function, which raises the Halstead volume and lowers MI without the logic changing. Expect a step at that release.
